Фильтр Калмана https://www.youtube.com/watch?v=HCd-leV8OkU. Есть внутреннее состояние системы и есть закон перехода этого состояния от одного шага времени к следующему. Есть проецирование этого состояния на измеримые (наблюдаемые) вещи. Также у состояния системы и у измерителей есть неотъемлемый шум. Задача - по измерения выйти на состояния и их переходы. 

TEM `[WhittingtonTEM]`. Есть отдельно структура (абстрактные локации и переходы между ними), и есть среда, которая связана с одной из выученных структур. Тогда поняв, какая структура соответствует среде, можно в этой среде начать ориентироваться. Читай - предсказывать состояние среды по наблюдениями. Т.е. опять же - есть скрытые переменные (структура) и есть наблюдаемые переменные (сенсорные ощущения). 

Идея в PyMC, фильтре Калмана, TEM - одни и те же. В PyMC задаём априорно структуру, которая ответственна (как нам кажется, как считаем) за формирование наблюдаемых данных, а потом по данным пытаемся найти точные параметры этой структуры. **"Понять" - найти апостериорное распределение латентных переменных**.

По-факту - смотрим на измерения и пытаемся адаптироваться. Саморегуляционная система.

Теория ограничения систем на примере офис-менеджера, который снабжает офис чай/кофе/печенки. https://vc.ru/id259530/675530-vlezaem-v-shkuru-ofis-menedzhera-osnovnye-algoritmy-snabzheniya. Тоже саморегуляционная система.

С бюджетингом тоже самое - просто "притираемся" к истинному тому, как оно идёт.
