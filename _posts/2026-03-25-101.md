В первую очередь важно выяснить, как располагаются данные в каждой из матрице: по строкам/по столбцам? Далее уже пляшется.

**Мнемоника 1**

<img src="/assets/2026-03-25/mnemonics-1.jpg" width="500"/>

Смотрим на умножение, как будто мы для каждого из \$V\$ строим путь из векторов \$E\$ (типа возьми столько-то \$e_1\$, добавь немного \$e_2\$, вычти чуть-чуть \$e_3\$ и т.д.). Для каждого вектора \$v_i\$, мы вычисляем линейную комбинацию векторов из \$E\$ (т.е. умножаем каждый вектор из \$E\$ на соотв. коэффициент из \$v_i\$ и суммируем итоговые вектора). 

Другими словами: **все компоненты** вектора \$e_i\$ сразу умножаются на соотв. элемент очередного вектора \$v\$ с последующим суммированием полученных векторов-столбцов

Интерпретация. матрица \$E\$ - базисные вектора (в старой системе координат), матрица \$V\$ - значения коэффициентов в системе координат этих базисных векторов. Первая колонка в результирующей матрицы есть координаты первого \$v\$ в старой системе координат.

**Мнемоника 2**

<img src="/assets/2026-03-25/mnemonics-2.jpg" width="500"/>

Берём все первые компоненты из каждого \$e_i\$ и взвешиваем ими каждую строку из матрицы \$V\$, где каждая строка матрицы \$V\$ - это покомпонентный срез (slice), т.е. первая строка - это все первые компоненты всех векторов из \$V\$, вторая строка - все вторые компоненты всех векторов из \$V\$ и т.д.

Другими словами: очередной срез из компонентов **всех векторов** \$E\$ масштабирует срезы компонентов из всех векторов \$V\$ с последующим суммированием векторов-строк

Интерпретация. матрица \$E\$ - базисные вектора (в старой системе координат), матрица \$V\$ - значения коэффициентов в системе координат этих базисных векторов. Первый срез по \$E\$, умноженный на \$V\$, даёт первые координаты всех \$V\$, которые будут первой строкой результирующей матрицы. Второй срез - вторая строка, где вторые координаты и т.д.

**Мнемоника 3**

<img src="/assets/2026-03-25/mnemonics-3.jpg" width="500"/>

То же самое, что и мнемоника 2, только транспонированный вариант. Работа со линейной комбинацией срезов.

**Мнемоника 4**

<img src="/assets/2026-03-25/mnemonics-4.jpg" width="500"/>

То же самое, что и мнемоника 1, только транспонированный вариант. Работа с линейной комбинацией векторов.

**Мнемоника 5**

<img src="/assets/2026-03-25/mnemonics-5.jpg" width="500"/>

Тут смотрим на умножение, как на скалярное произведение каждого вектора из \$E\$ с каждым вектором из \$V\$. 

Интерпретация 1. Матрица \$E\$ содержит стандартизированные значения каких-нибудь признаков (нулевое среднее и единичное стандартное отклонение). Матрица \$V=E^T\$. Тогда произведение этих матриц вычисляет матрицу ковариации

Интерпретация 2. Матрица \$E\$ содержит эмбеддинги (взвешенную сумму фича-векторов). Матрица \$V\$ есть координаты фича-векторов (их может быть очень много). Тогда произведение этих матриц вычисляет значения фичей. Т.е. каждая строка результирующей матрицы будет содержать для каждой фичи значение, закодированное в эмбеддинге для этой фичи. Или другими словами каждая строка будет содержать величины проекций эмебддинга на ось каждой из фичей. Если у нас 100 фичей, то строка будет содержать 100 элементов, где 1-ый элемент - величина проекции на ось первой фичи, 2-ой элемент - величина проекции на ось второй фичи и т.д.
